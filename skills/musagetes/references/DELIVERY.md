# 复核、清理与交付

## 每张专辑复核清单

分阶段读取下列清单。检查点只记录可观察结果，具体判定按对应规则；适用项全部通过并有证据才进入下一阶段，范围外项目注明理由。

### 发布前阻断检查

- [ ] 音乐身份、发行置信度、双源查询记录与逐轨匹配范围已确认。[来源门槛](SOURCES.md#名称与艺人检索及置信度门槛)、[部分匹配](SOURCES.md#完整匹配与部分匹配)
- [ ] 实际 codec、完整解码及适用的转换校验通过。[音频格式](AUDIO.md#音频格式)、[转码校验](AUDIO.md#转码校验)
- [ ] 适用必填项齐全或符合[缺失例外](METADATA_WHITELIST.md#可靠信息缺失例外)且已记录；原生读回与拟写字段、值、多值顺序一致，白名单校验通过。[字段与存储](METADATA_WHITELIST.md)、[读回流程](METADATA.md#白名单化流程)
- [ ] 标题、专辑及艺人变更都有保留或规范化依据；特殊署名已逐项核验。[内嵌值优先](METADATA.md#当前内嵌元数据优先)、[后缀](METADATA.md#apple-发行类型后缀清理)、[艺人](ARTISTS.md)
- [ ] 唯一正面封面身份、解码、尺寸、比例及嵌入读回通过。[封面](COVER.md)
- [ ] 成品碟轨统计和路径来自读回标签；整张路径计划无冲突，源可恢复，发布操作拒绝覆盖。[计数](METADATA_WHITELIST.md#轨号碟号与日期)、[路径](PATHS.md)、[事务](EXECUTION.md#事务与恢复)

### 清理前完整复核

先核对发布后的全部实际文件及指纹与上述证据一致，再完成适用分支：

- [ ] 实际写入的发行国家、受控流派、日期及选填值各有对应来源，层级与所选版本一致；允许的缺失有查询证据和原因。[白名单](METADATA_WHITELIST.md)、[流派](METADATA.md#genre-受控词表)、[来源优先级](SOURCES.md#来源优先级)
- [ ] 个人姓名、实体边界、角色及多值顺序在标签和路径中一致。[日文姓名](ARTISTS.md#日本艺人姓名空格规范化强制)、[连接符](ARTISTS.md#musicbrainz-艺人连接符处理强制)
- [ ] 合辑署名、角色/CV、客席及声库适用分支各有实体和角色证据。[合辑署名](ARTISTS.md#various-artists)、[CV](ARTISTS.md#角色歌曲与-cv-署名)、[客席](ARTISTS.md#featuring-与客席艺人)、[声库](ARTISTS.md#vocaloid-与歌声合成器)
- [ ] 人员、作品字段及输入别名均映射到规定存储，成对 credit 可逐项对照。[credit](METADATA_WHITELIST.md#表演类-credit-成对规则)、[输入别名](METADATA_WHITELIST.md#输入别名与最终键)
- [ ] 被排除介质、未匹配曲目及含未替代内容的压缩包均已独立登记。[介质](AUDIO.md#dvd-与-bd-碟排除与计数)、[部分匹配](SOURCES.md#完整匹配与部分匹配)
- [ ] 初始扫描内每个源文件都有成品、删除、归档保留或原位保留去向；新增或变化文件已重新核对，清理清单无未证明归属项。[清理](#清理)

### 清理后检查

- [ ] 成品目录符合[目标结构](PATHS.md#目标结构)，音轨数量和指纹仍与发布记录一致。
- [ ] 实际删除、归档及原位保留逐项对账，归档副本可读取且 SHA-256 一致；源目录残留与空目录处置都有结果或具体原因。
- [ ] 最终恢复快照覆盖所有仍存在的源、成品及保留数据，已删除路径可核对；报告链接到实际产物和记录。[跨运行记录](TOOLS.md#跨运行记录格式)

## 清理

清理在发布成功且全张适用复核通过后进行。执行前逐文件登记所属专辑、当前 SHA-256、处置和依据；执行时再次比对。文件变化、归属不明或未登记时原位保留。**扩展名本身不授权删除。**

| 对象 | 处置条件与结果 |
| --- | --- |
| 源 WAV、AIFF、APE、旧 FLAC、整轨镜像及其它已替代音频 | 仅在替代品全部校验通过且映射完整时删除 |
| CUE、LOG、已完全替代的压缩包及解压临时文件 | 所属音乐全部完成、恢复与来源证据已入记录后可删除；要求保留的 LOG 按保留资料处理 |
| 外置封面、扫图、booklet、封面候选 | 正确封面已嵌入并读回后按本 skill 的清理范围删除；用户明确保留的图片归档保留 |
| `Thumbs.db`、`desktop.ini`、`.DS_Store` | 属于当前源目录且逐项登记时可删除 |
| `.m3u`、`.m3u8`、`.md5`、`.sfv`、`.accurip`，以及抓轨生成的 `.nfo`、`.txt` | 读取内容确认仅描述本专辑旧路径、抓轨或校验结果，必要证据已保存且内容已失去用途时可删除；包含独特文字、歌词、授权说明或跨专辑引用时转入保留分支 |
| 有独立价值的文字、播放列表、校验说明、用户要求保留的资料及其它可确认归属的非音乐 sidecar | 归档到受保护状态位置的 `preserved/<album_id>/<原根目录相对路径>`；独占创建副本并验证 SHA-256 后才移除原文件，保留原路径映射。目标已占用即保留源并复核 |
| 未识别、不可读、归属不明、符号链接、被排除的 DVD / BD 及其专属资料 | 原位保留，逐项报告原因与路径；继续核验后再决定，音乐完成不解除这些保留条件 |

阻断性的身份、必填信息、CUE、转换、封面、读回或路径问题出现时，保留恢复所需全部源数据及原封面，暂停该专辑破坏性清理。已确认并妥善处理的部分匹配本身不阻断清理。含任何未替代介质或未知成员的压缩包保持原样。

### 空目录

逐文件处置结束后，按深度从深到浅核对计划内的源专辑目录及其子目录。仅对当时确实为空、归属明确、处于根目录内且不经过链接的目录执行 `rmdir`。根目录、状态目录、其它专辑目录及非空目录保留；竞态新增内容导致移除失败时记录残留。每个候选记录已移除或保留原因，不递归强删，不向上扩展到未列入计划的父目录。

## 状态与最终报告

以下是状态语义的唯一事实来源。执行结果、匹配范围和数据处置分别记录；例如成功整理的部分匹配专辑可同时有 `COMPLETED`、`PARTIAL_MATCH` 及归档资料的 `PRESERVED`。

| 维度 | 状态 | 含义及必报内容 |
| --- | --- | --- |
| 执行 | `COMPLETED` | 授权范围内适用校验、发布和清理全部结束；列实际最终路径。未执行的部分范围明确注明，不能据此声称全专辑完成 |
| 执行 | `SKIPPED` | 明确排除或不处理的内容，例如非音乐、DVD / BD、加密包；列范围和原因 |
| 执行 | `REVIEW_REQUIRED` | 证据、规则前提、历史归属或清理去向尚有阻断项；列缺失信息及恢复位置 |
| 执行 | `FAILED` | 实际解压、分轨、转码、标签、发布、清理或校验操作失败；列操作、错误及已产出结果 |
| 匹配 | `PARTIAL_MATCH` | 发行身份已确认，本地与公开曲目表不全同；分别列已匹配、本地额外及本地缺失曲目 |
| 处置 | `PRESERVED` | 刻意归档或原位保留的数据；列原路径、现路径、指纹及原因，不等同于执行失败 |

机器记录另以 `FULL` / `UNCONFIRMED` 表示完整匹配 / 尚未确认，未终结执行结果为 null。报告包含本轮处理、复用、跳过、待复核、失败和剩余数量，逐专辑实际状态与理由，非阻断性缺失字段及其查询证据、原因，以及删除、归档、原位残留、空目录各自的数量和路径。只写“保留源文件位置”不满足逐项对账要求。
