# 文件名与目录

## 目标结构

- 专辑目录：`[Album Artist][Album][Year]/`。同一发行的音乐碟扁平存放在该目录。
- 单碟音轨：`01 - Title - Artist.ext`；多碟音轨：`0101 - Title - Artist.ext`，即至少两位碟号接至少两位曲号。碟数和编号来自[排除 DVD / BD 后的音乐结构](AUDIO.md#dvd-与-bd-碟排除与计数)。
- 无专辑归属的单曲：根目录下 `[Artist][Title].ext`；保留其真实单曲身份。
- 年份取最终发行日期的四位年份，扩展名取实际成品格式。适用必填项及[允许的缺失记录](METADATA_WHITELIST.md#可靠信息缺失例外)核验后生成路径。
- 成品专辑目录只保留音轨；源目录的图片、CUE、LOG、其它 sidecar 及空目录均按[清理规则](DELIVERY.md#清理)逐项处置。用户明确要求原位保留的例外记录在交付中。

## 艺人显示

先完成[艺人规则](ARTISTS.md)的语义规范化，再将最终 `ARTIST` / `ALBUMARTIST` 的实际多值按原顺序用 ` & ` 拼接。固定组合名称内部的符号保持原样；`Various Artists` 也仅由已核验的实际标签值自然显示。显示文本仅用于路径。

## 路径字符

对构造出的完整目录名和文件名主体依次处理，标签原值保持不变：

1. 半角 `:` 换为全角 `：`。
2. `/`、`\`、`<`、`>`、`"`、`|`、`?`、`*` 及 Unicode 控制字符（类别 `Cc`）换为空格。
3. 合并连续空白，去掉首尾空白和尾部全部空格、点号。
4. Windows 设备名 `CON`、`PRN`、`AUX`、`NUL`、`COM1` 至 `COM9`、`LPT1` 至 `LPT9` 前加 `_`，大小写不敏感；带扩展名时也检查第一个点之前的名称。
5. 保留 Unicode 和有实际名称的前导点，例如 `.hidden`；空名称、`.`、`..` 不构成有效路径段。追加实际音频扩展名后再做整路径预检。

`.musagetes/` 及登记的其它状态目录受[工具级保护](TOOLS.md#状态目录保护)，即使名字本身合法也不作为音乐源或发布目标。路径碰撞、字节长度超限或需要截断才能落盘时，停止该专辑发布并复核；不覆盖，不擅加随机后缀。

## 确定性生成与预检

[scripts/music_rules.py](../scripts/music_rules.py) 的 `sanitize_component` 是上述字符规则的唯一实现；路径生成与预检共用它。使用 [render-paths 与 check-paths](TOOLS.md#从标签生成路径) 从最终标签生成计划，再核验指纹、冲突和状态边界。其它工具只负责执行已核验路径，不另维护 beets `replace` 或 fallback 模板。

预览使用拟写标签并标明预测结果；发布前使用原生读回后映射的最终标签重新生成。两次结果不同则重新核对计划。预检只覆盖检查时刻，实际发布仍使用拒绝覆盖的文件操作。
