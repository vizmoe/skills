# 音频处理

## 工具

| 工具 | 用途 |
| --- | --- |
| `kid3` / `kid3-cli` | 标签读写与复核 |
| `shntool` | 整轨分轨与检查 |
| `flac` | FLAC 编码、重压缩、完整性测试 |
| `beets` | 元数据辅助、预览和按已核验路径移动 |
| `mac` | APE 解码 |
| `ffmpeg` / `ffprobe` | 识别实际编解码器（codec）、解码、时长及流信息检查 |

可使用系统已安装的基础文件、编码和解压工具，如 `7z`、`unzip`、`bsdtar`、`unrar`、`iconv`。

此表列出能力选项，不要求全部安装。先检查当前步骤实际需要的工具与版本；等价实现须满足同样的无损、原生读回和安全要求。FLAC 原生标签可使用已安装的 `metaflac`。缺少必要能力时记录受影响步骤，不自动安装依赖。

## 扫描与解压

### 只读扫描

逐个扫描用户指定根目录及授权范围内的附赠子目录，建立完整来源组清单：全部本地音频、侧车和内嵌 CUE、压缩包、视频或镜像、图片与扫图、已有原生标签及内嵌封面，以及可能属于同一发行的文件集合。对整轨候选读取原生元数据块/标签，区分二进制 CUESHEET 与文本 CUE 等实际存储；先保存原始内容与指纹，再做标签白名单化，不能以缺少 `.cue` 文件推定没有 CUE。只读 inventory 的后缀提示不代替这一步，读取能力缺失时明确记未检查。

来源组记录稳定 ID、每个文件的 ID/路径/角色、媒体与预计曲数、CUE 来源类型和具体位置、切点验证及逐轨输出映射。扫描还须覆盖 bonus、postcard、page、special contents 等附赠内容，名称只作发现线索，不据此自动判成音乐或确认发行。音频进入后续队列；非音乐、缺源/重复 CUE、证据附件和未识别文件各自登记，不能静默丢弃或把附件数当作曲目数。

明确为音乐则处理；明确为非音乐则跳过；DVD / BD 碟及其内容按[介质排除规则](audio.md#dvd-与-bd-碟排除与计数)登记并跳过；类型不明则标记 `REVIEW_REQUIRED` 并保持原样。

### 压缩包

- RAR、ZIP、7z 等先解压到受控临时位置并检查内容；禁止归档路径逃逸到解压目标目录外。
- 解压前检查成员列表；绝对路径、`..`、符号链接、硬链接或特殊文件不能越过受控目录。仅有文件名检查不足以防止链接逃逸；工具不能保证边界时保持原包并标记复核。预览模式只列成员，不解压。
- 无法取得密码的加密包保持原样并记录。
- 原始压缩包按[原始文件策略](execution.md#文件角色与可选产物)默认保留；可处置的工作包仅在需处理的内容全部完成、通过最终校验且确认已被完整替代后才可进入清理。解压成功本身不构成删除条件；解压失败、内容不完整或替代情况不明时保留全部恢复资料。

## 音频格式

### 按实际 codec 决定处理方式

扩展名不能代替 codec 检查：`.m4a` 可能是 AAC 或 ALAC，`.ogg` 是容器，WAV/AIFF 也须确认实际编码。

| 来源 | 处理 |
| --- | --- |
| 可无损解码的无损音频，如 PCM WAV/AIFF、APE、ALAC | 转为 FLAC `-8` |
| FLAC | 先做完整性测试，再重编码为 FLAC `-8`；失败时保留原文件 |
| DSD，如 DSF、DFF | 不转码 |
| 有损音频，如 MP3、AAC、Vorbis、Opus、AC-3 | 不转码 |
| 视频容器，如 MKV、MP4 | 不按普通音频转码 |
| DVD / BD 碟及其镜像 | 按[介质排除规则](audio.md#dvd-与-bd-碟排除与计数)排除，不转码或提取音轨，保留源文件 |
| 其它光盘或镜像 | 仅在能可靠识别并安全处理为音频光盘时继续，否则跳过并记录 |

APE 优先用 `mac`，必要时用 `ffmpeg` 无损解码，再交给 `flac -8`。

### 转码校验

新输出至少满足：

- 命令成功，文件存在且非空，可完整读取和解码。
- 声道数、采样率、位深等关键参数无非预期变化。
- 时长或采样长度与源文件一致，或差异可解释。
- 专辑曲目数无非预期变化。

保留源音频至全部校验通过。

## 整轨与 CUE

1. 检查侧车及内嵌 CUE 的编码/存储类型、实际源绑定、索引顺序和可读性；两者并存时对照并记录选择依据，冲突不自动任选一份。
   侧车引用按 CUE 所在目录解析；内嵌 CUE 核对其宿主与真实音频边界。解析后的音频文件须位于获准根目录且不经过被跳过的链接；越界或来源不明时保留整轨并复核。旧扩展名引用先验证实际 codec、来源与索引对应，不能仅改后缀假装找到源；已由另一 CUE 覆盖的同一音频登记重复关系，不重复分轨。
2. 非 UTF-8 CUE 可在确保可回退后转换为 UTF-8，优先无 BOM。
3. CUE 可用时按索引分轨，再按[音频格式规则](audio.md#音频格式)处理音频格式。
4. CUE 乱码、损坏、引用错误或索引明显不一致时，禁止猜测时间戳分轨。网络曲目表仅用于确认曲目，不能代替可靠切点；边界不明时保留整轨并记录。
5. 分轨后检查曲目数、顺序、可解码性及总时长关系。
6. 整张专辑通过最终校验前，保留整轨、CUE 和 LOG。
7. 完整整理时，已验证分轨逐轨进入[整套发行检索](sources.md#整套发行与附赠内容发现)、标签、封面和归档队列。切点可靠只确认 audio 维度；没有发行关联也继续安全部分整理，不在分轨步骤提前结束。仅用户明确要求“只分轨”时交付该窄范围并说明未执行的后续步骤。
8. 收尾对照完整来源组和输出映射，每个实际音频都有已发布位置或具体复核原因，所有非音乐项目有明确处置。整轨对应多轨用一对多映射核对总数、顺序和音频区间；不能把 8 个整轨或 8 个 CUE 当作 8 首歌，也不能产生分轨成功但没有后续任务的音轨。

## DVD 与 BD 碟排除与计数

- **DVD 与 BD（Blu-ray Disc）均不纳入音乐成品的元数据处理范围。** 对可靠介质信息明确为 DVD 或 BD 的碟（包括 DVD-Video、DVD-Audio 及纯音频 Blu-ray），排除其曲目表、章节、碟号及专属艺人、credit 等信息；不得映射到音乐音轨或计入专辑艺人名单。不能仅凭文件名含有 `DVD`、`BD` 或 `Blu-ray` 就排除普通音轨或整张专辑。原始发行快照仍保留，用于确认版本，不能因过滤 DVD / BD 而混用其它发行的数据。
- **先排除 DVD / BD，再匹配音乐部分。** 本地与 MusicBrainz、Apple Music / iTunes 候选均先按介质过滤，[检索与匹配](sources.md)中的曲目数、碟数和总时长比较均以排除 DVD / BD 后的音乐部分为准。服务端无法按剩余音乐部分限定数量时，不以包含 DVD / BD 的发行总轨数或总碟数作为强制查询条件。仅因 DVD / BD 被排除造成的差异记为 `SKIPPED`，不算缺失音乐曲目，也不单独触发 `PARTIAL_MATCH`、低置信度或 `REVIEW_REQUIRED`。
- **总碟数只计排除 DVD / BD 后最终纳入成品的音乐碟。** 保持这些音乐碟的相对顺序，将 `DISCNUMBER` 连续编号为 `01` 至实际碟数，`DISCTOTAL` 使用该实际碟数；每碟的 `TRACKNUMBER` / `TRACKTOTAL` 也只描述该碟保留的音乐音轨。先按原始碟号、轨号建立可靠对应，再记录原碟号到成品碟号的映射，不为 DVD / BD 保留空碟号或占位曲目。
- 本地 DVD / BD 文件及其专属资料原样保留并记录 `SKIPPED`，不转码、提取音轨或并入成品音乐目录；只有 DVD / BD 的分组不生成空专辑。排除元数据不构成删除 DVD / BD 的依据，含未被完整替代 DVD / BD 内容的混合压缩包也须保留。

计数与路径示例（总碟数字段的最终键及输入别名见[元数据白名单](metadata-whitelist.md#轨号碟号与日期)）：

| 原发行介质 | 成品碟号与总碟数 | 文件名前缀 |
| --- | --- | --- |
| 1 CD + 1 DVD 或 BD | `DISCNUMBER=01`，`DISCTOTAL=01` | 单碟：`01`、`02`… |
| 2 CD + 1 DVD + 1 BD | `DISCNUMBER=01` / `02`，`DISCTOTAL=02` | 多碟：`0101`、`0201`… |
| 原碟 1 为 CD、碟 2 为 BD、碟 3 为 CD | 原碟 1、3 映射为成品碟 `01`、`02`，`DISCTOTAL=02` | 多碟：`0101`、`0201`… |
