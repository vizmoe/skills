# 封面

外部封面候选的身份与采用门槛按[检索与匹配规则](sources.md#名称与艺人检索及置信度门槛)核验。

候选来源为原内嵌封面、MusicBrainz / Cover Art Archive、Apple Music。本地外置图片只有可追溯至上述来源时，才作为该来源的缓存参与筛选；否则仅作发行核对线索，继续查询规定来源。用户明确指定使用的封面按本次授权处理，仍核验发行身份与比例。文件名 `cover` / `front` 或存放在专辑旁不能单独证明来源及身份。

仅采用已可靠确认属于同一发行的正面封面，并按以下顺序筛选：

1. **检查真实尺寸与比例。** 可先用 [cover-info](tools.md#封面尺寸预检) 读取 PNG/JPEG 头部筛选尺寸；头部通过后仍须完整解码。 解码图片读取宽 `W`、高 `H`，均须大于零；近似正方形定义为 `max(W, H) / min(W, H) ≤ 1.40`，即长边最多比短边长 40%。原内嵌图与下载图执行同一门槛，不凭文件名或 URL 中的尺寸推定合格。
2. **保持原始比例。** 如需缩放，等比例缩放并复核输出；不通过拉伸、裁切或补边使不合格图片过关，改查同一发行的合格正面封面。
3. **比较合格候选。** 先满足发行身份与比例要求，再优先选择像素数（`W × H`）较高者；像素数相同时优先文件体积较大者。记录来源、实际宽高、比例及选择或排除原因。

只选一张，格式支持时嵌入每轨；写入后读回核对唯一正面封面及实际尺寸、比例。最终成品不保留外置封面；候选可暂存于受控临时位置，嵌入并校验后必须删除。

支持嵌入封面但无可靠且比例合格的图片时，标记 `REVIEW_REQUIRED` 并说明缺失、身份不明或比例超限；保留可恢复的源文件与原封面，不标记 `COMPLETED`，不进入破坏性清理。
