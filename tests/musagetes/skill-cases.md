# Musagetes 行为验证

这些是维护用例，不随 skill 分发。使用隔离的合成文件或只读快照；禁止用真实音乐库做破坏性评测。独立前向验证时，只给执行代理实际请求、skill 路径与原始材料，不提供本文件的验收结论。判断实际计划和产物，而非要求复述特定措辞。

## 触发范围

| 用户请求 | 应有行为 |
| --- | --- |
| 「整理这个目录的音乐，统一成专辑目录」并提供绝对路径 | 使用 skill，先扫描和计划再按授权执行 |
| 「只预览这些 FLAC 的标签修复」 | 使用 skill，只读媒体；路径为拟写标签的预测结果 |
| 「用 CUE 给这张整轨分轨」 | 使用音频分支，检查引用与索引；不自行扩大为整库改标签和清理 |
| 「推荐几张日本爵士专辑」「播放我的歌单」 | 不触发该 skill |
| 「给播客批量编号」「下载这张专辑」 | 不触发该 skill |
| 「改进 musagetes skill 的描述」 | 维护 skill，不执行音乐整理 |

## 领域与安全分支

| 原始材料或情景 | 可检查的结果 |
| --- | --- |
| 请求未给音乐根目录 | 询问实际目录；无个人默认库、无历史路径写入 |
| 本地 12 轨，可靠来源仅 11 轨，特典轨已有可信标题和艺人 | 前 11 轨逐轨对应，特典轨保留可信曲目值并补可靠专辑值；记录 `PARTIAL_MATCH`，不整体放弃或伪造第 12 轨 |
| 原碟 CD / BD / CD，曲目表及介质已可靠确认 | 音乐碟连续为 01 / 02、总碟数 02；BD 原样保留并记录 `SKIPPED`，不形成缺曲或空碟号 |
| `麻枝 准 × 熊木杏里`，结构化来源有两个 artist ID | 日文个人姓名按规则规范化；标签为两个有序值，路径用 ` & ` |
| `Simon & Garfunkel` 对应单一实体 | 保存单值固定组合，不按 `&` 拆分 |
| MusicBrainz joinphrase 为空或未列举的 Unicode 字符 | 仍按 artist-credit 实体边界处理；不以有限分隔符正则漏过多值 |
| 原 `ALBUMARTIST=Various Artists`，仅 MusicBrainz 支持，Apple 无法核实 | 不能视为成品已验证；查可靠实际专辑艺人，否则 `REVIEW_REQUIRED` |
| 可靠 CV / Featuring / 声库参与记录 | 按对应角色语义保存主署名及配对表演 credit，不机械追加为主艺人 |
| 可信标题 `Rain: / 夜` 与平台标点不同 | 标签保留可信原文；仅路径清理非法字符；不能以平台展示差异改标签 |
| `.m4a` 内分别是 AAC 与 ALAC | 按实际 codec 分别保留与无损转 FLAC；后缀不能决定转码 |
| CUE 引用 `../../outside.wav` 或损坏索引 | 保留整轨和 CUE，标记复核；不猜切点、不读取未授权引用 |
| 归档内链接或路径可逃逸；含未替代 BD | 阻断不安全解压；音乐部分完成也不删除混合原包 |
| 只有比例 1.8 的封面或身份不明的大图 | 不拉伸裁切补边；无合格替代时保留源数据并阻断完成 |
| 专辑旁有本地 front.png，但无规定来源记录且用户未明确指定它 | 只作核对线索；不把位置或文件名当成可采用来源 |
| 目标已有同名、大小写或 Unicode 等价文件 | 整张停止发布，目标与源都未被覆盖 |
| 预检后源内容变化或发布时新目标出现 | 旧计划失效或发布拒绝覆盖；保留已产出与源文件供恢复 |
| 再次处理已完成且指纹未变的专辑 | 复核并复用结果，不凭目录名跳过，也不重复转码清理 |
| 网络一侧持续不可用或必要工具缺失 | 有限重试并记录；继续可确定部分，不降低采用门槛，不自动安装 |
| 标签工具将两个艺人折叠成单值或封面读回失败 | 不能报告 `COMPLETED` 或清理源文件 |

## 本轮新增回归场景

| 情景 | 可检查结果 |
| --- | --- |
| 英文 organize my music folder / fix these tags / split this CUE | 可发现对应技能与窄分支；显式调用可复现 |
| 已发布源目录含 m3u、md5、accurip 与自写 nfo / txt | 逐项读取并判断归属和价值；过时派生物可计划删除，独立资料归档保留，扩展名本身不授权删除 |
| 清理后源专辑子目录为空，父目录还有其它专辑 | 仅列计划内确实为空的源子目录，用 rmdir；保留根、状态和其它专辑目录 |
| 新 run_id、旧运行已有完成记录 | 枚举历史、沿用 album_id，以最新 sequence 和当前 SHA-256 对账；再核对新增文件与领域证据 |
| 较早完成记录之后存在损坏记录或相同 sequence | 阻断自动复用，不能回退到旧完成记录 |
| 最新指纹全同，但新增 sidecar 或 skill 版本不同 | helper 候选仍需当前 inventory / 领域复核；不会仅按终态跳过 |
| 200 张队列，指定 limit=12，已有 5 张通过复用复核 | 复用不占 limit，其余实际入队最多 12 张；默认 10 张一批，报告剩余与检查点 |
| 连续三张实际操作失败，夹有 SKIPPED 或 REVIEW_REQUIRED | 暂停该根后续写入并给出原因和下一步；这些非失败结果不增加或重置失败计数 |
| 状态路径为 .musagetes、大小写变体或登记的嵌套替代位置 | inventory 排除，诊断时标状态资料；音乐源、目标与 keep 均受保护 |
| 路径含前导点、Windows 设备名、尾点空格组合 | 按一个函数规范化；渲染结果通过名称检查，碰撞另外阻断 |
| 临时在白名单表新增一个选填键 | 解析器即时识别；输入别名与排除表不混入允许集 |
| PNG/JPEG 比例恰为 1.40，或多一个像素；仅有完整图片头 | 整数边界判定准确；头部不冒充完整解码或发行身份校验 |
| 已读回 tags 含冒号、非法路径字符或多个艺人 | 只清理生成路径，标签保持原值和顺序；生成计划接入 check-paths |
| 冷门发行查证后 COUNTRY 或受控 GENRE 无可靠信息 | 可逐字段省略并记录原因与查询证据；其它完成条件满足后可 COMPLETED，仅此缺失不阻断发布或清理 |
| 一个例外字段已有可靠值，另一个仍无法确定 | 保留可靠值，只为实际缺失字段提供 omissions；不因允许缺失而丢弃可信标签 |
| 以缺失例外省略 TITLE、DATE 等其它必填项，或缺失原因为空 | 校验阻断；允许字段从白名单表读取，例外不扩大范围 |
| 根目录是指向外置卷的链接 | 错误包含可传入的解析后真实路径；库内链接仍保持原样 |
| 通过 skills CLI 安装到临时项目 | helper 与白名单解析正常，无安装目录缓存或媒体写入 |

## 自动化检查

在仓库根目录运行 `python3 -B -m unittest discover -s tests/musagetes -v` 检查字段、几何、路径安全、跨运行恢复和无写入副作用。运行 `python3 -B -m unittest discover -s tests -v` 验证资源边界，以及通过真实 skills CLI 安装后脱离源码运行。

运行 `python3 -B scripts/validate_skills.py` 执行官方格式验证、链接、锚点与资源可达性检查。验证环境的安装命令见[仓库说明](../../README.md#维护)。

本文件是验收场景集，不声称已完成每个场景的真实端到端运行。独立前向验证的请求、原始输入指纹、实际产物和结果记录放在隔离 work 目录；在交付中区分自动化测试、实际代理跑过的场景与仅作规范审阅的场景。
