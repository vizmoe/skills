# Standards and dependency evidence

Scripted-note behavior was checked on 2026-10-08 against [EPUB 3.3 scripted content](https://www.w3.org/TR/epub-33/#sec-scripted-content), [reading-system scripting](https://www.w3.org/TR/epub-rs-33/#sec-scripted-content) and [Playwright browser contexts](https://playwright.dev/docs/api/class-browsercontext). EPUB permits scripting; the `scripted` declaration does not distinguish a footnote from other interaction. Reader scripting support varies. The explicit constrained note checker, automatic-case selection, resource-preserving reading repair and continued publication prohibition are Quillbind policies. Browser interaction evidence does not certify native reader popups. See [note checks](../../../skills/quillbind/references/notes.md).

Legacy entity compatibility was checked on 2026-09-12 against W3C's XHTML [Latin-1](https://www.w3.org/TR/xhtml1/DTD/xhtml-lat1.ent), [symbol](https://www.w3.org/TR/xhtml1/DTD/xhtml-symbol.ent) and [special](https://www.w3.org/TR/xhtml1/DTD/xhtml-special.ent) declarations: 253 static character names, including XML's predefined entities. The bundled numeric table is used only with recognized XHTML public declarations; arbitrary DTDs and internal subsets remain blocked. Static SVG CSS follows the [SVG styling mechanisms](https://www.w3.org/TR/SVG2/styling.html), checked 2026-09-12. Restricting SVG CSS resource loading and active behavior is Quillbind security policy, not a standards-wide ban on styling.

Browser coverage and screenshot retention policies were added on 2026-09-12. Full coverage remains the default; explicitly selected stratified reader-mode coverage and heuristic storage projections are described in [quality](quality.md). These are local QA policies, not EPUB conformance rules. EPUBCheck, Ace and platform checks are unaffected.

Personal reading repair policy was added on 2026-09-08: preserve existing EPUB versions, keep source semantics, and report EPUBCheck, sampled browser and platform findings independently of publication release. Hyperlink handling follows [HTML links](https://html.spec.whatwg.org/multipage/links.html#links-created-by-a-and-area-elements), checked 2026-09-08: an anchor without `href` is not a hyperlink. Ordinary HTTP(S), mailto and tel destinations are retained as data and never fetched by validation. Shared NCX parsing uses the [DAISY NCX declaration](https://daisy.org/z3986/2005/Z3986-2005.html), checked 2026-09-08, without loading DTDs. Reader width constraints, missing-font fallback cleanup and CSS punctuation repair are local repair policy, not new conformance requirements.

Navigation and cover generation were checked on 2026-09-06 against [EPUB navigation and spine rules](https://www.w3.org/TR/epub-33/#sec-nav-def), [Apple navigation](https://help.apple.com/itc/booksassetguide/en.lproj/itc0f175a5b9.html), [Kindle navigation](https://kdp.amazon.com/en_US/help/topic/GY3AD8C6C6GAG42N) and [Kindle cover guidance](https://kdp.amazon.com/en_US/help/topic/G6GTK3T3NUHKLEFX). Kindle recommends a clickable HTML contents page near the beginning and supports a `toc` landmark. Its cover guidance asks for an OPF-declared cover image without an additional HTML cover page, to avoid duplicate covers or conversion failure. This is a KDP submission difference, not an EPUB-wide ban on cover XHTML. Quillbind follows the explicitly selected Apple Books preference: it retains a separate cover page, generates image alternative text from the book title and authors, leaves the background undefined as described by [Apple's in-book cover guidance](https://help.apple.com/itc/booksassetguide/en.lproj/static.html), and excludes the KDP cover-page difference from platform lint. Repairs preserve source cover pages. The top-level contents entry, localized labels, centered contents heading and unnumbered nested lists are Quillbind defaults, not vendor-mandated wording or decoration. See [architecture](architecture.md) for the generated structure.

Cover-resolution guidance was checked on 2026-09-06 against [Apple Book Cover Art](https://help.apple.com/itc/booksassetguide/en.lproj/static.html). Apple recommends at least 1400 pixels on the short edge for external marketing artwork and distinguishes it from the interior cover. Quillbind applies that recommendation to configured raster `cover.path` images as the nonblocking authoring diagnostic `COVER_RESOLUTION_LOW`; SVG is exempt. This is project policy, not an EPUB validation error. The source remains unchanged, and agent workflows continue while reporting the warning.

Platform lint scope was narrowed on 2026-09-06 by project policy: KDP publication-language eligibility and additional HTML cover-page review are no longer checks and do not change diagnostics or distribution status. Historical source references remain [Kindle cover guidance](https://kdp.amazon.com/en_US/help/topic/G6GTK3T3NUHKLEFX) (checked 2026-09-06) and [Kindle supported languages](https://kdp.amazon.com/en_US/help/topic/G200673300) (last checked 2026-09-05).

Official sources were checked on 2026-09-05. EPUB 3.3 remains the production target. Recommendations, working drafts, informative notes, platform guidance and project policy are recorded separately. A newer draft does not change the output target. `standards/registry.json` is copied into build reports.

The [EPUB 3.3 errata index](https://w3c.github.io/epub-specs/epub33/errata.html) was reviewed. Its dynamic issue lists are not interpreted as evidence of zero open errata. Platform rules record a checked date because the vendor pages can change independently of an EPUB specification. The [CommonMark specification](https://spec.commonmark.org/0.31.2/) is the Markdown basis; GFM, math and directives are explicit parser extensions documented in the authoring guide.

The exact library versions, licenses, release dates, repositories and package integrity values are recorded in `standards/dependencies.lock.json`; installed transitive versions are in `pnpm-lock.yaml`. Java and EPUBCheck archive checksums and Node runtime evidence are in `standards/tools.lock.json`. Docker base images use immutable platform digests.

Stable toolchain sources: [Node.js Current](https://nodejs.org/en/download/current), [Temurin 26 releases](https://github.com/adoptium/temurin26-binaries/releases), [Python release](https://www.python.org/downloads/release/python-3147/), [EPUBCheck releases](https://github.com/w3c/epubcheck/releases), [Ace releases](https://github.com/daisy/ace/releases), and the official npm registry for each package. Selected versions and integrity records are authoritative in [tools.lock.json](../standards/tools.lock.json), [package.json](../package.json), [dependencies.lock.json](../standards/dependencies.lock.json) and the pnpm lock.

Quillbind uses primary sources for normative rules. LCC-inspired categories are a local controlled vocabulary, not an assertion of official catalog classification. Professional publisher guidance informs conservative layout defaults without being relabeled as a W3C requirement. Automated accessibility checks and platform lint results retain their actual scope in release reports.

Read-only [inspection](../../../skills/quillbind/references/inspection.md) follows the [EPUB navigation document](https://www.w3.org/TR/epub-33/#sec-nav-def), [spine item references](https://www.w3.org/TR/epub-33/#sec-itemref-elem) and [legacy OPF/NCX relationships](https://idpf.org/epub/20/spec/OPF_2.0.1_draft.htm). Source URLs were checked on 2026-09-05. Inspection preserves original package metadata and reports structure; it is separate from conformance validation and does not add a platform rule.

The known NCX doctype is recognized from [DAISY's NCX example in Z39.86-2005](https://daisy.org/z3986/2005/Z3986-2005.html), checked 2026-09-05. Inspection removes only that declaration in memory, without loading its DTD; other external declarations and internal entity subsets remain blocked.

[Markdown style coverage](markdown.md) records the CommonMark/GFM authoring subset and the optional [CJK-friendly parsing extension](https://github.com/tats-u/markdown-cjk-friendly). Quote borders and spacing are Quillbind defaults, informed by Apple font guidance and Kindle's distinction between body text and special paragraphs; they are not vendor-mandated decoration. Sources checked on 2026-09-05.

[Blog import coverage](blog-markdown.md) records [Astro's Markdown conventions](https://docs.astro.build/en/guides/markdown-content/), GitHub heading slugs and the Properties whitelist. Named-note syntax was also checked against [Hugo/Goldmark](https://gohugo.io/configuration/markup/) and [Python-Markdown](https://python-markdown.github.io/extensions/footnotes/). EPUB notes follow [Apple pop-up markup](https://help.apple.com/itc/booksassetguide/en.lproj/itccf8ecf5c8.html) and [Kindle bidirectional links](https://kdp.amazon.com/en_US/help/topic/GQ6JQ7FM6C72HE4X); native pop-up behavior remains a reader feature. Whitelist selection, aliases and the chapter byline are Quillbind policy. Sources checked on 2026-09-05.

Platform lint rule version `1.3.0` uses [Kindle image guidance](https://kdp.amazon.com/en_US/help/topic/G75V4YX5X8GRGXWV), [Kindle table guidance](https://kdp.amazon.com/en_US/help/topic/GZ8BAXASXKB5JVML) and the text/Apple sources above. It distinguishes source-size policy from vendor constraints: image pixel and table-size findings are warnings without automatic resizing or truncation. Chinese script subtags, CMYK color, unsupported Kindle MathML elements and nested tables are format findings. Vertical writing is set on the document root. PNG recompression follows [PNG Third Edition](https://www.w3.org/TR/png-3/) with the pinned [Node zlib API](https://nodejs.org/api/zlib.html); [image processing](images.md) records preservation guarantees and the WebP compatibility decision. These sources were checked on 2026-09-05.

BookWalker product fields were checked on 2026-10-08 against [Taiwan volume 1](https://www.bookwalker.com.tw/product/177922) and [Japan volume 1](https://bookwalker.jp/dee3662059-f2a0-493d-bc6b-d6db793fa8b4/). Taiwan exposes product-specific structured page data; its series count is not a volume number. Japanese dates come from the current work-information block: `底本発行日` first, then `配信開始日`. Original-date preference is user-selected catalog policy, not an EPUB requirement. Contributor roles and series refinements use [EPUB package metadata](https://www.w3.org/TR/epub-33/#sec-pkg-metadata). Live pages are outside CI; synthetic fixtures preserve their structures without redistributing store content.

Manga CBZ metadata follows [ComicInfo 2.0](https://anansi-project.github.io/docs/comicinfo/schemas/v2.0), checked 2026-10-08; 2.1 remains a draft. The official schema and its MIT license are preserved under `standards/comicinfo/`, with source revision and hashes in `source.json`. Tests validate actual archive metadata using `xmllint --nonet` against that schema. JPEG XL lossless encoding and reversible JPEG reconstruction follow [libjxl](https://github.com/libjxl/libjxl), checked 2026-10-08. The container uses checksum-pinned Ubuntu arm64 codec packages compatible with the pinned base, while runtime reports identify the installed codec version. Numeric page order, verification limits and creator-role mappings are Quillbind policy. JPEG XL support in CBZ readers is a separate compatibility requirement, not implied by EPUB platform checks.

[Embedded metadata maintenance](../../../skills/quillbind/references/embedded-metadata.md) maps the library's controlled labels to ComicInfo 2.0 `Genre` and EPUB `dc:subject`; the shared label set is library policy, not a standard taxonomy. The [ComicInfo field documentation](https://anansi-project.github.io/docs/comicinfo/documentation), [EPUB subject metadata](https://www.w3.org/TR/epub-33/#sec-opf-dcsubject) and [EPUB modification date](https://www.w3.org/TR/epub-33/#sec-metadata-last-modified) were checked on 2026-10-08. This is a scoped maintenance procedure, separate from scan packaging and publication release; it does not change their runtime contracts.
